# Java Encapsulation Programs

This repository contains Java programs demonstrating **Encapsulation** in Object-Oriented Programming (OOP).

These programs were created to practice and understand how data can be protected by restricting direct access to class fields and providing controlled access through methods.

## 📚 Concepts Covered

* Encapsulation in Java
* Data Hiding
* Access Modifiers
* `private` variables
* Getter methods
* Setter methods
* Controlled Access to Data
* Class and Object Concepts

## 🔐 What is Encapsulation?

Encapsulation is an OOP concept that combines data and methods inside a class while restricting direct access to the internal data.

In Java, encapsulation is commonly achieved by:

* Declaring instance variables as `private`
* Providing `public` getter methods to read data
* Providing `public` setter methods to modify data
